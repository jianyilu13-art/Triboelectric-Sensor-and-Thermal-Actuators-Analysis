# MLE4228/MLE5241 Laboratory Projects
### Fabrication and Characterization of Triboelectric Sensors & Thermal Actuators

This repository contains two laboratory projects completed for **MLE4228/MLE5241 – Robotic Materials** at the **National University of Singapore (NUS)**.

The projects focus on the design, fabrication, characterization, and analysis of smart materials for robotic applications, including triboelectric sensors and thermal actuators (artificial muscles).

# Projects

## 1. Triboelectric Sensor

This project investigates the fabrication and characterization of contact-separation triboelectric sensors using different material combinations.

### Topics

- Material sensitivity comparison
- Force response and linearity analysis
- Sensor sensitivity calculation
- Frequency response
- Repeatability analysis
- Thermal interference study
- Self-powered LED demonstration

### MATLAB Analysis

The MATLAB programs included in this repository perform:

- Signal preprocessing
- Peak extraction
- 50 Hz power-line noise filtering
- Linearity analysis
- Repeatability analysis
- Automatic figure generation

---

## 2. Thermal Actuator

This project investigates twisted fishing-line thermal actuators (artificial muscles) for soft robotic applications.

### Topics

- Thermal actuator fabrication
- Temperature–strain characterization
- Stress–strain relationship
- Material comparison
- Diameter comparison
- Repeatability evaluation

The experimental analysis was performed primarily using **Tracker Video Analysis**, where displacement and strain were extracted from recorded experiments.
